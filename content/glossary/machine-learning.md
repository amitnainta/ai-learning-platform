Machine learning (ML) is the dominant approach behind modern
[artificial intelligence](glossary:artificial-intelligence). Instead of a
programmer writing explicit rules, a model is shown examples
([training data](glossary:training-data)) and an
[algorithm](glossary:algorithm) adjusts the model's internal values so its
predictions get closer to correct over time. Most of what's called "AI" in
everyday conversation — recommendation engines, image recognition, large
language models — is built on machine learning.
