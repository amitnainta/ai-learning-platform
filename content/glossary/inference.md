Inference is the act of using an already-trained [machine learning](glossary:machine-learning)
model to make a prediction on new input — as distinct from training, which
is the earlier process of building the model in the first place. When you
send a message to a chatbot, the response is generated at inference time,
using [parameters](glossary:parameter) that were already fixed during
training.
