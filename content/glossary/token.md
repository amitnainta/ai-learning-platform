A token is a chunk of text — often a whole word, part of a word, or a
punctuation mark — that a [large language model](glossary:large-language-model)
treats as a single unit of input or output. Rather than working with raw
characters, an LLM breaks text into tokens, converts each into a numeric
representation, and generates its response one token at a time. Model
providers often price and rate-limit API usage by token count.
